Spring AI Demo
===================================

Prerequisitos
============

- Maven
- Java 21

Ejecución
============

1- Compilación del código en línea de comando. En la carpeta raíz del proyecto lanzar el siguiente comando:

```
mvn clean install
```

2 - Ejecución de aplicación. En la carpeta raíz del proyecto lanzar el siguiente comando:

```
mvn clean spring-boot:run
```

3 - Ejecutar la aplicación de la rama 'springai-mcp-client' para poder interactuar con este server.

4 - Ejecutar la colección Postman disponible en la rama 'springai-mcp-client'.
